# G-Product Intelligence

吉利系 / 比亚迪 / 奇瑞 产品情报墙：架构 → 平台 → 车型。

- Overview：层级 / 泳道 / 矩阵
- Architecture：滑板底盘与架构对比
- **Learn（学习）**：架构 → 平台 → 车型 → 参数/性能；重点速通 08 · Z20 · 20 · 900；Cmd+K 快查车型/平台/极氪学要点与陷阱
- Relations：同源 / 同平台关系
- Compare：架构与车型对照

数字以公开口径与课件为准，待补不编造。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:8080`。

## 技术栈

React 19 · TanStack Start · Vite · Tailwind CSS
